Telegram-бот с инлайн-интерфейсом для ежедневного трекинга продуктивности: чек-ины,
статистика, библиотека PDF-материалов, реферальная программа, платная подписка через
**Telegram Stars** и полноценная админ-панель прямо внутри Telegram — без единой
внешней веб-страницы.

Проект собран как готовый шаблон: механику чек-ина, контент, тарифы и брендинг легко
адаптировать под любую нишу — фитнес-коучинг, онлайн-курсы, менторские программы,
клубы по подписке и т.д.

> ⚠️ Ниже — демо-версия для презентации: тестовый бот и тестовая админ-панель с
> демонстрационными данными. В боевом проекте бот разворачивается на сервере клиента
> (Docker/VPS) под его брендингом, контентом и тарифами.

## Возможности

- **✅ Ежедневный чек-ин** — оценка дня от 1 до 10, короткая заметка, автоматический
  расчёт стрика и среднего балла (7/30 дней). Механику легко заменить под любую
  ключевую метрику бизнеса (тренировки, обучение, привычки и т.д.).
- **📊 Статистика** — текущий и лучший стрик, средние баллы, история чек-инов с пагинацией.
- **📚 Библиотека материалов** — гайды, тренировки и лекции в PDF по категориям;
  часть контента можно закрыть подпиской — готовый механизм платного доступа.
- **👥 Реферальная система** — персональная ссылка на каждого пользователя, бонусные
  дни подписки за приглашённого друга. Встроенный виральный рост без доп. настройки.
- **⭐ Монетизация через Telegram Stars** — несколько тарифов, готовый флоу оплаты
  (`send_invoice` → `pre_checkout_query` → `successful_payment`), без сторонних
  платёжных провайдеров и комиссий эквайринга.
- **🛠 Админ-панель прямо в боте** — аналитика (DAU/WAU/MAU, доход, конверсия, топ
  контента), управление пользователями (выдача премиума, бан), CRUD контента и
  тарифов, массовая рассылка — всё без отдельной веб-панели, которую нужно ещё
  где-то размещать и защищать.
- **🌐 Мультиязычность** — переключаемый интерфейс RU/EN, легко добавить любой язык.
- **⏰ Напоминания** — автоматический пуш тем, кто ещё не сделал чек-ин сегодня.

## Стек

Python 3.11+, aiogram 3, SQLAlchemy 2.0 (async) + SQLite (безболезненно переезжает на
Postgres/MySQL при росте нагрузки), APScheduler, pydantic-settings. Бот работает на
long polling, поэтому не требует домена и SSL-сертификата — деплоится одной командой
на любом сервере или в контейнере.

## Быстрый старт (локально)

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`:

1. `BOT_TOKEN` — получите у [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. `ADMIN_IDS` — ваш числовой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)).
   Через запятую можно указать несколько администраторов.
3. `TIMEZONE` — таймзона для ежедневных напоминаний (по умолчанию `Europe/Moscow`).

Запуск:

```bash
python -m bot.main
```

При первом запуске бот сам создаст файл БД и засеет демо-контент (по одному материалу
на каждую категорию) и 3 тарифа подписки — библиотека и подписка не будут пустыми
даже без ручной настройки.

## Запуск в Docker

```bash
copy .env.example .env
docker compose up -d --build
```

Готово для деплоя на любой VPS/облако — подробности в [DEPLOYMENT.md](DEPLOYMENT.md).

## Как стать администратором

Добавьте свой Telegram ID в `ADMIN_IDS` в `.env` и перезапустите бота. После этого
в главном меню появится кнопка «🛠 Админка» (также доступна команда `/admin`).
Из админки можно: смотреть аналитику, выдавать/отзывать премиум, банить пользователей,
управлять контентом и тарифами подписки, делать рассылку — без обращения к разработчику.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты покрывают ключевую логику: расчёт стриков, реферальные бонусы, консистентность
переводов ru/en и математику продления подписки.

## Структура проекта

```
bot/
  main.py            # точка входа
  config.py           # настройки из .env
  database/            # модели SQLAlchemy + репозитории
  handlers/              # хендлеры пользователя и админ-панели
  keyboards/               # inline-клавиатуры
  middlewares/               # сессия БД, контекст пользователя, активность
  services/                    # стрики, i18n, рефералы, Stars, планировщик
  locales/                       # ru.json / en.json
sample_guides/           # демо PDF-материалы
scripts/                  # генератор демо-PDF, сидер БД
screenshots/               # скриншоты интерфейса для этого README
tests/                      # юнит-тесты (pytest)
```

## Возможные доработки под конкретный проект

- Собственный брендинг, тексты и контент под нишу заказчика.
- Другая ключевая метрика вместо «продуктивности» (вес, тренировки, учебный прогресс и т.д.).
- Индивидуальные таймзоны пользователей.
- Веб-версия админ-панели, если нужен доступ не из Telegram.
- Возвраты (refunds) для платежей Stars, промокоды, пробный период.
- Alembic-миграции и переход на Postgres при масштабировании.
