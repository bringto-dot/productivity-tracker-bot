Telegram-бот на **aiogram 3**, который помогает пользователю ежедневно оценивать свою
продуктивность: чек-ины, статистика, библиотека PDF-гайдов/тренировок/лекций,
реферальная программа, платная подписка через **Telegram Stars** и полноценная
встроенная админ-панель. Портфолио-проект: полностью рабочий, с тестами и Docker.

## Возможности

- **✅ Ежедневный чек-ин** — оценка дня от 1 до 10, короткая заметка, автоматический
  расчёт стрика и среднего балла (7/30 дней).
- **📊 Статистика** — текущий и лучший стрик, средние баллы, история чек-инов с пагинацией.
- **📚 Библиотека материалов** — гайды, тренировки и лекции в PDF по категориям;
  часть материалов может быть доступна только по подписке.
- **👥 Реферальная система** — персональная ссылка, бонусные дни подписки за приглашённого
  друга (начисляются после его первого чек-ина).
- **⭐ Подписка за Telegram Stars** — несколько тарифов, встроенный `send_invoice`,
  обработка `pre_checkout_query` / `successful_payment`.
- **🛠 Админ-панель прямо в боте** — аналитика (DAU/WAU/MAU, доход, топ материалов),
  управление пользователями (премиум/бан), CRUD гайдов и тарифов, рассылка всем.
- **🌐 RU/EN** — переключаемый язык интерфейса для конечных пользователей.
- **⏰ Напоминания** — ежедневный пуш тем, кто ещё не сделал чек-ин (APScheduler).

## Стек

Python 3.11+, aiogram 3, SQLAlchemy 2.0 (async) + SQLite, APScheduler,
pydantic-settings, long polling (без вебхука — не нужен домен/SSL).

## Быстрый старт (локально)

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`:

1. `BOT_TOKEN` — получите у [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. `ADMIN_IDS` — ваш числовой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)).
   Через запятую можно указать несколько администраторов.
3. `TIMEZONE` — таймзона для ежедневных напоминаний (по умолчанию `Europe/Moscow`).

Запуск:

```bash
python -m bot.main
```

При первом запуске бот сам создаст файл БД (`bot.db`) и засеет 3 демо-материала
(по одному на каждую категорию) и 3 тарифа подписки — библиотека и подписка не будут
пустыми даже без ручной настройки.

## Запуск в Docker

```bash
copy .env.example .env
docker compose up -d --build
```

БД сохраняется в `./data/bot.db` на хосте (volume), контейнер можно пересоздавать
без потери данных.

## Как стать администратором

Добавьте свой Telegram ID в `ADMIN_IDS` в `.env` и перезапустите бота. После этого
в главном меню появится кнопка «🛠 Админка» (также доступна команда `/admin`).
Из админки можно: смотреть аналитику, выдавать/отзывать премиум, банить пользователей,
добавлять/удалять PDF-материалы, управлять тарифами подписки и делать рассылку.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты покрывают чистую логику: расчёт стриков, реферальные бонусы, консистентность
переводов ru/en и математику продления подписки — без необходимости поднимать бота
или реальный Telegram API.

## Структура проекта

```
bot/
  main.py            # точка входа
  config.py           # настройки из .env
  database/            # модели SQLAlchemy + репозитории
  handlers/              # хендлеры пользователя и админ-панели
  keyboards/               # inline-клавиатуры
  middlewares/               # сессия БД, контекст пользователя, активность
  services/                    # стрики, i18n, рефералы, Stars, планировщик
  locales/                       # ru.json / en.json
sample_guides/           # 3 демо PDF-гайда
scripts/                  # генератор демо-PDF, сидер БД
tests/                      # юнит-тесты (pytest)
```

## О хостинге

Бот работает на long polling — не нужен домен, SSL-сертификат или публичный IP,
поэтому его можно спокойно гонять локально для демонстрации. Варианты бесплатного
постоянного хостинга — в [DEPLOYMENT.md](DEPLOYMENT.md).

## Возможные доработки

- Alembic-миграции вместо `create_all` при более сложной схеме.
- Индивидуальные таймзоны пользователей (сейчас одна таймзона на весь бот).
- Веб-версия админ-панели, если понадобится доступ не из Telegram.
- Возвраты (refunds) для платежей Stars.
